# Marvelversed

Marvelversed is a fan-made browser game created by Abhijith Krishnan. It combines a character quiz (Unmasked) and a puzzle game (Fragmentum), with single-player and multiplayer modes.

Live game: https://www.marvelversed.com/

## What I built

- Interactive quiz and puzzle gameplay for solo or multiplayer play.
- A React and Next.js interface styled with Tailwind CSS.
- Character content drawn from the Marvel API.

## Run locally

Requires Node.js and npm. From the repository root, run npm install and then npm run dev. Open http://localhost:3000.
